# 03. Equipment (Экипировка)

## Обзор

Экипировка устанавливается в слоты корабля и дронов:
- **Laser Guns** — наносят урон
- **Shield Generators** — дают щит
- **Speed Generators** — дают скорость
- **Extensions** — специальные модули/умения

**Важно:** Генераторы щита и скорости делят ОДНИ слоты! Нельзя поставить и то и другое.

## Стратегии экипировки — КОНФИГУРАЦИИ

### Config 1 — FARM (Максимальный урон для фарма)

```
Цель: Максимальный урон + защита

КОРАБЛЬ:
├── Lasers: Все LG-4
└── Generators: ВСЕ SG-3 (щиты)

ДРОНЫ:
└── Все слоты: LG-4 (лазеры)

Результат:
- Максимальный урон (все пушки в дронах!)
- Максимальная защита корабля
- Медленная скорость (нет двигателей)

Использование: Фарм NPC, основной режим
```

### Config 2 — ESCAPE (Максимальная скорость для побега)

```
Цель: Максимальная скорость + выживаемость

КОРАБЛЬ:
├── Lasers: Все LG-4 (но урон меньше)
└── Generators: ВСЕ ACC-3 (двигатели)

ДРОНЫ:
└── Все слоты: SG-3 (щиты)

Результат:
- Минимальный урон (только корабль)
- Максимальная скорость
- Щиты на дронах для выживания

Использование: Побег, эвакуация, PvP убегание
```

## Пример билда для Hecate

### Config 1 — FARM

```
Ship: Hecate (15 laser slots, 15 gen slots)

КОРАБЛЬ:
- Lasers (15): 15 × LG-4 (175 dmg) = 2,625 base
- Generators (15): 15 × SG-3 = 240,000 shield

ДРОНЫ (8 × 2 slots = 16):
- Все: 16 × LG-4 = 2,800 base damage

ИТОГО:
- Total Damage: 5,425 base × ammo × upgrades
- Shield: 240,000
- Speed: Базовая (медленный)
```

### Config 2 — ESCAPE

```
КОРАБЛЬ:
- Lasers (15): 15 × LG-4 = 2,625 base
- Generators (15): 15 × ACC-3 = +150 speed

ДРОНЫ (16 slots):
- Все: 16 × SG-3 = 256,000 shield

ИТОГО:
- Damage: 2,625 base (ТОЛЬКО корабль!)
- Shield: 256,000 (от дронов)
- Speed: Базовая + 150 (БЫСТРЫЙ)
```

## Формула общего урона

```
Total Damage = (Ship Lasers + Drone Lasers) × Ammo × Upgrades

Пример Config 1:
Ship: 15 × LG-4 = 2,625
Drones: 16 × LG-4 = 2,800
Base Total: 5,425

× 4 (x4 ammo) = 21,700
× 1.2 (Dungid 20%) = 26,040 damage/sec

Пример Config 2:
Ship: 15 × LG-4 = 2,625
Drones: 0 (щиты!)
Base Total: 2,625

× 4 (x4 ammo) = 10,500
× 1.2 (Dungid 20%) = 12,600 damage/sec
```

---

## Ключевые правила

```
1. Генераторы щита и скорости делят ОДНИ слоты
2. На дронов НЕЛЬЗЯ ставить двигатели
3. Config 1 = щиты в корабле + пушки в дронах
4. Config 2 = двигатели в корабле + щиты в дронах
```

## Приоритеты для бота

### Начальный этап
```
1. LG-2 или LG-3 — доступны за BTC
2. SG-2 — базовая защита
3. ACC-2 — для Config 2
```

### Средний этап
```
1. LG-4 — макс урон
2. SG-3 — макс щит
3. ACC-3 — макс скорость
```

### Улучшение ресурсами
```
1. Darkonit — сразу +10% урона
2. Uranit — +8% к щитам
3. Dungid/Xureon — когда доступны
```
