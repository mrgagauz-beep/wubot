# 02. Ships (Корабли)

## Обзор

Корабли — основа геймплея. Каждый корабль имеет:
- HP (здоровье)
- Скорость (базовая)
- Слоты для лазеров
- Слоты для генераторов (щиты ИЛИ двигатели)
- Слоты для Extensions (умения)
- Cargo (грузовой отсек)

**Важно:** Дроны — отдельная система! Если у вас 8 дронов, они будут на ВСЕХ кораблях.

## Конфигурации корабля

Каждый корабль имеет **2 конфигурации** (config):

### Config 1 — FARM (Максимальный урон)

```
КОРАБЛЬ:
- Generators: ВСЕ слоты → SG-3 (щиты)
- Lasers: Все LG-4

ДРОНЫ:
- ВСЕ слоты → LG-4 (лазеры)

Результат:
- Максимальный урон (все пушки в дронах)
- Максимальная защита корабля (все щиты)
- Медленная скорость (нет двигателей)

Использование: Основной фарм NPC
```

### Config 2 — ESCAPE (Максимальная скорость)

```
КОРАБЛЬ:
- Generators: ВСЕ слоты → ACC-3 (двигатели)
- Lasers: Все LG-4 (но урон меньше без дронов)

ДРОНЫ:
- ВСЕ слоты → SG-3 (щиты)

Результат:
- Максимальная скорость (все двигатели)
- Максимальная защита дронов (выживаемость)
- Минимальный урон

Использование: Побег от врагов, эвакуация, PvP убегание
```

### Переключение конфигурации

```
Горячие клавиши: Настраиваются в Settings
UI: Стрелки слева от панели боеприпасов
Эффект: Мгновенная смена экипировки
```

## Пример конфигураций для Hecate

### Config 1 — FARM

```
Ship: Hecate (15 laser slots, 15 gen slots)

КОРАБЛЬ:
- Lasers (15): 15 × LG-4 (175 dmg each) = 2,625 base
- Generators (15): 15 × SG-3 = 240,000 shield
- Speed: Только базовая (медленный)

ДРОНЫ (8 штук, 2 слота каждый = 16 слотов):
- Все слоты: 16 × LG-4 = 2,800 base damage

ИТОГО:
- Damage: 2,625 + 2,800 = 5,425 base
- Shield: 240,000
- Speed: Базовая (медленный)
```

### Config 2 — ESCAPE

```
КОРАБЛЬ:
- Lasers (15): 15 × LG-4 = 2,625 base
- Generators (15): 15 × ACC-3 = +150 speed
- Speed: Базовая + 150 (БЫСТРЫЙ)

ДРОНЫ (8 штук = 16 слотов):
- Все слоты: 16 × SG-3 = 256,000 shield

ИТОГО:
- Damage: 2,625 base (только корабль!)
- Shield: 256,000 (от дронов)
- Speed: Максимальная
```

## Дроны — отдельная система!

**Важно понимать:**

```
Дроны НЕ привязаны к кораблю!
Если у вас 8 дронов — они будут на ВСЕХ ваших кораблях.

Дроны покупаются отдельно:
- Basic дроны (BTC)
- Ares дроны (PLT)

Максимум: 8 дронов
Слоты в дроне: 1-2 (зависит от типа)
```

См. [Drones](./04_DRONES.md) для подробностей.

## Система накопления (для бота)

Вместо продажи карго можно использовать несколько кораблей:

```
1. Фарм на Ship A пока cargo full
2. Подлететь к порталу (или любой safe zone)
3. Переключиться на Ship B
4. Фарм на Ship B пока cargo full
5. Переключиться на Ship C
6. ...
7. Когда все корабли заполнены — продолжаем фарм БЕЗ сбора лута
```

### Где можно менять корабль

```
Корабль можно менять в ЛЮБОЙ Safe Zone на союзной карте:
- У любого портала (если safe zone активна)
- На базе фракции (X-7)
- У Space Station (если есть на карте)
- На стартовых картах (X-1) — везде безопасно!

Не нужно лететь на базу — достаточно быть в safe zone!
```

### Преимущества

- Меняем корабль прямо у портала где фармим
- Не нужно лететь на базу
- Больше времени на фарм
- Оптимизация ресурсов
