# 05. Aliens/NPCs (Пришельцы)

## Обзор

Aliens (NPC) — основные противники для фарма:
- Дают EXP, Honor, BTC, ресурсы
- Разные типы на разных картах
- Имеют варианты: Normal, Hyper, Ultra
- Некоторые агрессивные, некоторые пассивные

## Варианты NPC

### Normal (Обычные)

```
Базовые характеристики
Встречаются на всех картах
Стандартные награды
```

### Hyper (Усиленные)

```
Префикс: H (например HHydro, HJenta)
HP: ~2x от Normal
Урон: ~1.5x от Normal
Награды: Увеличены
Встречаются: X-4+, Star Missions
```

### Ultra (Ультра)

```
Префикс: U (например UHydro, UJenta)
HP: ~4x от Normal
Урон: ~2x от Normal
Награды: Значительно увеличены
Встречаются: X-6+, Star Missions (Zeta+)
Особенность: Дропают WLX-4 боеприпасы
```

## Описания NPC

### Hydro
```
"Самые примитивные существа в галактике."
- Первый NPC для новичков
- Пассивный: атакует только если атакован
- Легко убивается
- Хорош для изучения механик
```

### Jenta
```
"Небольшие, но быстрые существа."
- Немного сильнее Hydro
- Пассивный
- Более высокая скорость
```

### Mali
```
"Скрытая дикая сила за маленьким размером."
- Агрессивный: атакует первым
- Высокая скорость
- Часто в группах
- Требует осторожности у новичков
```

### Plarion
```
"Средний хищник космоса."
- Агрессивный
- Первый "серьёзный" моб
- Требует хорошей экипировки
```

### Bangoliour
```
"Высшая форма развития Jenta и Mali."
- Очень быстрый
- Высокий урон
- Собирается в стаи
- Хрупкая броня (уязвим к хорошим патронам)
```

### Zavientos
```
"Ужасные, отвратительные, очень проворные существа."
- Чувствуют страх на расстоянии
- Опасны в группах
- Высокие награды
```

### Quattroid
```
"Легендарный босс."
- Более 1 млн HP
- Дропает редкие предметы
- Требует группы или топ экипировки
- Дропает WLX-4 (Ultra форма)
```

---

## Поведение NPC

### Пассивные

```
Типы: Hydro, Jenta
Поведение:
- Не атакуют первыми
- Атакуют только после получения урона
- Преследуют атакующего
- Легко фармить
```

### Агрессивные

```
Типы: Mali, Plarion, Motron, и все сильные
Поведение:
- Атакуют при приближении
- Радиус агрессии ~1000-1500 единиц
- Преследуют до смерти
- Могут собираться в группы
```

## Рекомендации для бота

### Выбор цели

```java
float scoreTarget(NPC npc) {
    float score = 1000;
    
    // Ближе = лучше
    score -= distance(player, npc) * 0.1f;
    
    // Меньше HP = быстрее убить
    score -= npc.hp * 0.001f;
    
    // Бонус за лут рядом
    score += nearbyBoxes * 100;
    
    // Штраф за опасных
    if (npc.type == BOSS) score -= 500;
    
    return score;
}
```

### Приоритет по типам

```
1. Слабые с лутом рядом
2. Уже атакующие игрока
3. Ближайшие
4. Средние
5. Сильные (только если готов)
```

### Избегание

```
Избегать если:
- HP игрока < 30%
- NPC уровня выше допустимого
- Много агрессивных NPC рядом (>3)
```
