# 06. Resources (Ресурсы)

## Обзор

Ресурсы собираются с убитых NPC и используются для:
- Продажи за Bitcoin (BTC)
- Переработки в более ценные ресурсы
- Улучшения экипировки (лазеры, щиты, скорость, ракеты)

---

## Классификация ресурсов

### Primary Resources (Первичные)

Самые распространённые, собираются на X-1, X-2, X-3.

| Ресурс | Карты | Описание |
|--------|-------|----------|
| **Cerium** | X-1, X-2 | Самый базовый |
| **Mercury** | X-2 | Улучшенный |
| **Erbium** | X-2, X-3 | Продвинутый |
| **Piritid** | X-3 | Лучший первичный |

### Secondary Resources (Вторичные)

Получаются из переработки первичных или с сильных NPC.

| Ресурс | Получение | Эффект улучшения |
|--------|-----------|------------------|
| **Darkonit** | Рефайн, Cargo drop | +10% урон лазеров/ракет |
| **Uranit** | Рефайн, Cargo drop | +4% урон, +8% щит/скорость |
| **Azurit** | Рефайн, Cargo drop | +5% скорость, +10% щит |

### Rare Resources (Редкие)

Очень ценные, сложно получить.

| Ресурс | Получение | Эффект улучшения |
|--------|-----------|------------------|
| **Dungid** | Рефайн, Покупка, Редкий дроп | +20% урон лазеров/ракет |
| **Xureon** | Рефайн, Покупка, Редкий дроп | +10% скорость, +20% щит |

## Refining (Переработка)

Первичные ресурсы можно переработать во вторичные.

### Рецепты переработки

```
Cerium + Mercury → Darkonit
Erbium + Piritid → Uranit
Mercury + Erbium → Azurit
Darkonit + Uranit → Dungid
Azurit + Uranit → Xureon
```

*Примечание: Точные рецепты могут отличаться, проверьте в игре*

### Где перерабатывать

```
Место: Control Panel → Equipment → Resources
Требуется: Быть на базе или иметь Premium (Autorefine)
```

### Premium Autorefine

```
С Premium: Автоматическая переработка
Без Premium: Ручная переработка на базе
```

## Сбор ресурсов

### Cargo Drop

После убийства NPC падает Cargo с ресурсами.

```
Действие: Подлететь к боксу → CollectableCollectRequest
Y_OFFSET: +97 (важно для протокола!)
Радиус сбора: ~600-900 единиц
```

### Типы боксов

| Type | Название | Собирать? |
|------|----------|-----------|
| 1 | BONUS_BOX | ✅ Всегда |
| 2 | RESOURCE_1 | ❌ Игнорировать |
| 3 | RESOURCE_2 | ❌ Игнорировать |
| 4 | LOOT | ✅ Если есть место |
| 13 | SPECIAL_1 | ❌ Игнорировать |
| 14 | SPECIAL_2 | ❌ Игнорировать |

## Стратегия для бота

### Вариант 1: Продажа

```
1. Фарм NPC → собирать Cargo
2. Когда Cargo полный → лететь на базу
3. Продать всё за BTC
4. Повторить
```

**Плюсы:** Простая логика
**Минусы:** Много времени на перелёты

### Вариант 2: Накопление на кораблях

```
1. Фарм на Ship A → Cargo full
2. Сменить на Ship B → Cargo full
3. Сменить на Ship C → Cargo full
4. Когда все корабли заполнены → продать/рефайн
```

**Плюсы:** Меньше перелётов, больше фарма
**Минусы:** Сложнее логика

### Вариант 3: Рефайн для улучшений

```
1. Фарм первичных ресурсов
2. Рефайн в Darkonit/Dungid
3. Улучшить лазеры (+20% урон)
4. Фарм эффективнее
```

## Cargo Management

### Размеры Cargo по кораблям

| Корабль | Cargo |
|---------|-------|
| Shuttle | 100 |
| Zephyrus | 250 |
| Thorus | 500 |
| Veles | 750 |
| Calipso | 1000 |
| Hecate | 2000 |
| Hyperion | 3000 |

### Определение полного Cargo

```java
// Из пакета GameStateResponsePacket
int cargoUsed = player.getChange(PARAM_CARGO_USED);
int cargoMax = player.getChange(PARAM_CARGO_MAX);

boolean isFull = cargoUsed >= cargoMax;
boolean isAlmostFull = cargoUsed >= cargoMax * 0.9;
```

### Действия при полном Cargo

```
1. Прекратить сбор Cargo боксов
2. Продолжать собирать Bonus Box (не занимает место)
3. Лететь на базу для продажи
   ИЛИ
4. Сменить корабль (если есть)
```
