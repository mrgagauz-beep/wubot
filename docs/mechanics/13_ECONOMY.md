# 13. Economy (Экономика)

## Обзор

Экономика WarUniverse основана на двух валютах:
- **Bitcoin (BTC)** — игровая валюта (фарм)
- **Platinum (PLT)** — премиум валюта (донат)

Дополнительно: **Gold** — для Premium и магазина.

---

## Bitcoin (BTC)

### Получение

| Источник | Количество |
|----------|------------|
| Убийство NPC | 10 - 50,000 |
| Продажа ресурсов | Зависит от типа |
| Bonus Boxes | 100 - 10,000 |
| Квесты | 10,000 - 500,000 |
| Star Missions | 25,000 - 150,000 |

### Использование

- Покупка кораблей (BTC корабли)
- Покупка экипировки (LG-1/2/3, SG-1/2, ACC-1/2)
- Покупка боеприпасов (x1, x2)
- Покупка ракет (NC-30)
- Ремонт корабля

### Средний фарм BTC

```
X-1 (Hydro, Jenta): ~10,000 BTC/час
X-2 (Jenta, Mali): ~25,000 BTC/час
X-3 (Mali, Plarion): ~50,000 BTC/час
X-5 (Bangoliour): ~200,000 BTC/час
X-6 (Zavientos): ~500,000 BTC/час
```

*Примечание: Зависит от экипировки и эффективности*

## Platinum (PLT)

### Получение

| Источник | Количество |
|----------|------------|
| Покупка за реальные деньги | Основной |
| Star Missions | 25,000 - 200,000 |
| Квесты | 5,000 - 50,000 |
| Events | Разное |
| Убийство сильных NPC | 100 - 1,000 |

### Использование

- Корабли (PLT корабли)
- Элитная экипировка (LG-4, SG-3, ACC-3)
- Элитные боеприпасы (x3, x4, x6)
- Элитные ракеты (TNC-130)
- Дроны (Ares)
- Extensions
- Premium

---

## Gold

### Получение

- Покупка за реальные деньги

### Использование

- Premium подписка
- Специальные предметы
- Ускорение прогресса

---

## Auction (Аукцион)

### Механика

```
Продолжительность: 1 час
Лоты: Случайные, обновляются каждый час
Ставки: Возвращаются при проигрыше
```

### Что продаётся

- Корабли (Hyperion-J — 15-е число)
- Дроны
- Экипировка
- Дизайны
- Боеприпасы

### Советы

```
1. Следить за редкими лотами
2. Ставить в последние минуты
3. Не переплачивать за обычные предметы
```

---

## Ремонт корабля

### Стоимость

```
С Premium: Бесплатно
Без Premium: 500 PLT

Место: Safe Zone (база)
```

### Условия бесплатного ремонта

```
- Premium активен
- Находиться в Safe Zone
- Автоматический ремонт HP и Shield
```

## Стратегия экономии для бота

### Начальный этап

```
1. Не тратить PLT
2. Копить BTC на Hecate
3. Использовать BTC экипировку (LG-3, SG-2, ACC-2)
```

### Средний этап

```
1. Фарм PLT через Star Missions
2. Покупка LG-4, SG-3, ACC-3
3. Покупка Ares дронов
```

### Поздний этап

```
1. Покупка PLT корабля
2. Полная элитная экипировка
3. Улучшение ресурсами
```
