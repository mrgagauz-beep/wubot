# 09. Leveling & Rank (Уровни и ранг)

## Обзор

Система прогрессии в WarUniverse:
- **Level** — открывает доступ к картам и контенту
- **Rank** — позиция в таблице лидеров
- **Honor** — репутация (влияет на Rank)
- **Battle Rank** — позиция среди PvP игроков

---

## Experience Points (EXP)

### Получение EXP

- Убийство NPC (основной источник)
- Убийство игроков
- Выполнение квестов
- Star Missions
- Events

## Honor Points (HNR)

### Получение Honor

- Убийство NPC
- Убийство игроков (больше Honor)
- Star Missions
- Events

### Потеря Honor

- Смерть от игрока
- Атака союзников (в некоторых режимах)

### Влияние Honor

- Rank в таблице лидеров
- Некоторые скидки при высоком Honor

---

## Rank System

### Компоненты Rank

```
Rank = f(EXP, Honor, NPC Points, Quest Points)
```

### NPC Points (Временные)

```
Особенность: Временные очки
Срок действия: 1 месяц после убийства NPC
Эффект: Быстрый подъём в рейтинге
Предупреждение: Со временем уменьшаются
```

### Quest Points (Постоянные)

```
Особенность: Постоянные очки
Получение: Выполнение квестов
Эффект: Стабильный Rank
Исключение: DCS Quests не считаются
```

---

## Battle Rank

```
Что это: Отдельный рейтинг PvP
Основа: Убийства игроков
Бейджи: Специальные значки за достижения
```

## Ограничения по уровням

### Защита новичков

```
Низкоуровневые игроки не могут:
- Сражаться с высокоуровневыми
- Получить урон от высокоуровневых (на некоторых картах)
- Заходить на опасные карты
```

### Доступ к контенту

| Контент | Минимальный уровень |
|---------|---------------------|
| Star Missions | Level 7+ |
| T-1 (Spaceball) | Level 9+ |
| Auction | Level ? |
| Clan creation | Level ? |

## Прокачка для бота

### Быстрая прокачка (1-7)

```
Карты: X-1 → X-2 → X-3
NPC: Hydro → Jenta → Mali
Стратегия: Убивать всё подряд
Время: 1-3 дня активного фарма
```

### Средняя прокачка (7-15)

```
Карты: X-3 → X-4 → X-5
NPC: Mali → Plarion → Bangoliour
Стратегия: Осторожный фарм, избегать PvP
Время: 1-2 недели
```

### Поздняя прокачка (15-20)

```
Карты: X-5 → X-6 → X-7
NPC: Bangoliour → Zavientos → Raider
Стратегия: Star Missions + фарм
Время: Несколько недель
```
