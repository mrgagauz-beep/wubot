# 04. Drones (Дроны)

## Обзор

Дроны — **отдельная система**, не привязанная к кораблям:
- Если у вас 8 дронов — они на ВСЕХ ваших кораблях
- Добавляют слоты для лазеров ИЛИ щитов
- Летают вокруг корабля автоматически
- Максимум 8 дронов

**Важно:** На дронов НЕЛЬЗЯ ставить двигатели (ACC)!

---

## Типы дронов

### Стандартные дроны

| Тип | Слоты | Получение |
|-----|-------|-----------|
| Basic | 1 | Shop (BTC) |
| Improved | 1 | Shop (PLT) |
| Advanced | 2 | Shop (PLT) |

### Элитные дроны

| Дрон | Слоты | Способности | Получение |
|------|-------|-------------|-----------|
| **Ares** | 2 | +5% урона, +10% щита | Shop (PLT), Auction |

#### Ares

```
Слоты: 2
Пассивные бонусы:
- +5% к урону лазеров НА ЭТОМ ДРОНЕ
- +10% к щиту генераторов НА ЭТОМ ДРОНЕ

Получение:
- Shop (PLT)
- Аукцион
```

---

## Экипировка дронов

### Что МОЖНО ставить

- **Lasers** (LG-1 до LG-4) — для урона
- **Shield Generators** (SG-1 до SG-3) — для защиты

### Что НЕЛЬЗЯ ставить

- ❌ Speed Generators (ACC) — НЕЛЬЗЯ!
- ❌ Extensions — только на корабль

---

## Роль дронов в конфигурациях

### Config 1 — FARM (все пушки в дронах)

```
ДРОНЫ: Все слоты → LG-4

Пример с 8 Ares (16 слотов):
16 × LG-4 (175) = 2,800 base damage

Результат: Максимальный урон
```

### Config 2 — ESCAPE (все щиты в дронах)

```
ДРОНЫ: Все слоты → SG-3

Пример с 8 Ares (16 слотов):
16 × SG-3 (16,000) = 256,000 shield

Результат: Максимальная защита для выживания
```

## Drone Covers (Дизайны дронов)

Специальные скины для дронов с бонусами.

### DCD (Damage Drone Cover)

```
Эффект: +10% к урону лазеров на дроне с DCD
Бонус за полный сет: Нет
Получение:
- First Star Mission (100% шанс)
- Максимум 5 DCD (1 с каждой первой Star Mission)
```

### DCS (Shield Drone Cover)

```
Эффект: +10% к щиту генераторов на дроне с DCS
Бонус за полный сет: Нет
Получение через квесты:
- Level 11: Reaper
- Level 14: Code Blue
- Level 15: Hyperbolization
- Level 16: Radioactive Adventures
- Level 17: Blade Runner
- Level 18: Hammer and Sickle
- Level 19: Hyperbolization II
- Level 20: Ultrabolization
(1 с каждого квеста)
```

### DCH (Honor Drone Cover)

```
Эффект: Бонус к Honor очкам
Получение: Квесты, события
```

## Расчёт урона с дронами (Config 1)

### Формула

```
Drone Damage = Σ(Drone Lasers) × Ammo × Upgrades × Design Bonus

Пример с 8 Ares + DCD:
8 × 2 × LG-4 = 16 × 175 = 2,800 base
× 4 (x4 ammo) = 11,200
× 1.2 (Dungid) = 13,440
× 1.1 (DCD на каждом) = ~14,000+
```

### Общий урон корабля (Config 1)

```
Total = Ship Damage + Drone Damage

Hecate + 8 Ares (Config 1 - FARM):
Ship: 15 × LG-4 × 4 × 1.2 = 12,600
Drones: 16 × LG-4 × 4 × 1.2 = 13,440
≈ 26,000+ damage/sec
```

---

## Расчёт щита с дронами (Config 2)

### Формула

```
Drone Shield = Σ(Drone Shields) × Upgrades × Design Bonus

Пример с 8 Ares + DCS:
16 × SG-3 (16,000) = 256,000 base
× 1.2 (Xureon) = 307,200
× 1.1 (DCS на каждом) = ~338,000 shield
```

---

## Дроны не привязаны к кораблям!

```
Важно понимать:

✓ Купил 8 Ares дронов
✓ Они автоматически на ВСЕХ твоих кораблях
✓ Переключил корабль — дроны те же самые
✓ Настроил Config на одном — применяется на всех

Это значит:
- Нужно купить дронов только ОДИН раз
- Экипировка дронов сохраняется между кораблями
- Config 1/2 влияет на дронов одинаково везде
```

## Визуальное представление

```
        ●  ●
       ●    ●
     [SHIP]
       ●    ●
        ●  ●
        
● = Дрон (летает вокруг)
```

Дроны:
- Автоматически следуют за кораблём
- Атакуют ту же цель что и корабль
- Не могут быть уничтожены
- Не требуют управления

---

## Дизайны дронов — БЕЗ разделения по конфигам!

```
ВАЖНО:
- Дизайн дрона (DCD/DCS) ОДИНАКОВЫЙ на обеих конфигурациях!
- Нельзя поставить DCD для Config 1 и DCS для Config 2
- Меняется только ЭКИПИРОВКА (лазеры ↔ щиты)
- Дизайн остаётся тот же

Пример:
- Поставил DCD на 5 дронов
- Config 1: эти 5 дронов с DCD + лазеры (+10% урона)
- Config 2: эти же 5 дронов с DCD + щиты (DCD не даёт бонус к щитам)
```

### Оптимальная стратегия дизайнов

```
Так как фарм (Config 1) — основной режим работы:
- Ставим DCD на максимум дронов (5 штук с First Star Missions)
- Остальные 3 дрона — без дизайна или DCS

DCD даёт +10% урона → полезно в Config 1
DCS даёт +10% щита → полезно в Config 2

Но т.к. большую часть времени бот в Config 1:
→ Приоритет DCD
```

---

## Стратегия для бота

### Начальный этап

```
1. Купить Basic дроны за BTC (8 штук)
2. Config 1: поставить LG-2 или LG-3
3. Config 2: поставить SG-2
```

### Средний этап

```
1. Купить Ares за PLT (8 штук)
2. Config 1: все LG-4
3. Config 2: все SG-3
4. Получить DCD с First Star Missions (5 штук)
5. Получить DCS с квестов
```

### Продвинутый этап

```
1. Полный сет Ares (8 штук)
2. DCD на 5 дронах (приоритет для фарма)
3. DCS на остальных 3 дронах (или без дизайна)
4. Улучшение ресурсами

Помни: дизайны НЕ меняются между конфигами!
```
