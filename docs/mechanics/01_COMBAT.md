# 01. Combat System (Боевая система)

## Обзор

Боевая система в WarUniverse основана на:
- Захвате цели (lock)
- Лазерной атаке (постоянный урон)
- Ракетной атаке (разовый урон)
- Орбитальном движении (kiting)

---

## Основные действия

### 1. Lock (Захват цели)

```
Действие: Выбрать цель для атаки
Пакет: UserActionsPacket(actionId=2, value="targetId")
Подтверждение: Сервер отправляет PARAM_TARGET_ID (id=20)
```

**Важно:** Нужно дождаться подтверждения от сервера перед атакой!

### 2. Attack (Начать атаку)

```
Действие: Начать лазерную атаку
Пакет: UserActionsPacket(actionId=3, value="")
Продолжительность: Автоматически до смерти цели или команды Stop
```

### 3. Stop Attack (Остановить атаку)

```
Действие: Прекратить атаку
Пакет: UserActionsPacket(actionId=4, value="")
```

### 4. Rocket (Ракетная атака)

```
Действие: Выстрелить ракетой
Тип: Мануальный запуск (клик по иконке ракеты)
Cooldown: Зависит от типа ракеты и Premium статуса
```

## Формулы урона

### Базовый урон

```
Total Damage = (Ship Lasers + Drone Lasers) × Ammo Multiplier × Upgrades
```

### Пример расчёта

```
8 × LG-4 (175) = 1400 базового урона
+ 8 дронов × LG-4 (175) = 1400
= 2800 базового урона

С x4 патронами: 2800 × 4 = 11200 урона/сек
С Dungid (+20%): 11200 × 1.2 = 13440 урона/сек
```

## Kiting (Орбитальная атака)

### Концепция

```
1. Подлететь к NPC на дистанцию атаки
2. Заблокировать (Lock)
3. Начать атаку (Attack)
4. Двигаться по орбите вокруг NPC
5. NPC следует за игроком, но не догоняет
6. Урон наносится постоянно
```

### Дистанции Kite

| HP NPC | Kite Distance | Retreat Distance |
|--------|---------------|------------------|
| < 70k | 750 | 650 |
| 70k-500k | 800 | 700 |
| > 500k | 850 | 750 |

### Алгоритм Orbit

```java
// Каждые 200-350ms
if (distance < retreatDistance) {
    // Отступить от NPC
    moveAwayFrom(npc);
} else if (distance > kiteDistance + 150) {
    // Догнать NPC
    moveTowards(npc);
} else {
    // Орбитальное движение
    orbitAngle += 2°;
    targetX = npc.x + kiteDistance * cos(orbitAngle);
    targetY = npc.y + kiteDistance * sin(orbitAngle);
    moveTo(targetX, targetY);
}
```

## Конфигурации корабля

Каждый корабль имеет **2 конфигурации**:

### Config 1 — FARM (Максимальный урон)

```
КОРАБЛЬ:
- Generators: ВСЕ → SG-3 (щиты)
- Lasers: Все LG-4

ДРОНЫ:
- Все слоты → LG-4 (лазеры)

Результат: Макс урон, макс защита, медленный
Использование: Основной фарм NPC
```

### Config 2 — ESCAPE (Максимальная скорость)

```
КОРАБЛЬ:
- Generators: ВСЕ → ACC-3 (двигатели)
- Lasers: Все LG-4

ДРОНЫ:
- Все слоты → SG-3 (щиты)

Результат: Макс скорость, щиты для выживания
Использование: Побег, эвакуация, избегание врагов
```

### Переключение конфигурации

```
Действие: Клик на стрелки в UI или горячая клавиша
Эффект: Мгновенная смена экипировки
Не прерывает: Текущую атаку
Когда: При угрозе — переключить на Config 2 и убегать
```

## Последовательность боя

```
┌─────────────────────────────────────────────┐
│           COMBAT SEQUENCE                    │
├─────────────────────────────────────────────┤
│                                             │
│  1. Найти NPC                               │
│     └── Приоритет: близость + HP + лут      │
│                                             │
│  2. Подлететь к NPC                         │
│     └── Smooth movement (шаги 300-400px)    │
│     └── Предсказание позиции NPC            │
│                                             │
│  3. Lock цель                               │
│     └── Отправить LOCK пакет                │
│     └── Ждать подтверждения (до 2 сек)      │
│                                             │
│  4. Начать атаку                            │
│     └── Отправить ATTACK пакет              │
│                                             │
│  5. Orbit loop                              │
│     └── Поддерживать дистанцию              │
│     └── Движение каждые 200-350ms           │
│     └── Собирать боксы (MOVE→ЖДАТЬ→COLLECT) │
│                                             │
│  6. NPC умер                                │
│     └── Собрать лут                         │
│     └── Найти следующего NPC                │
│                                             │
└─────────────────────────────────────────────┘
```
